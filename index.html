🔗 Partager le dashboard
Diffusez une version consultable de « votre projet » ou générez un QR code.

Scannez ce QR code pour accéder au dashboard sur smartphone. Pour une consultation optimale, exportez d'abord la version HTML et déposez-la sur un partage OneDrive/SharePoint public.

📱 Comment l'utiliser :
1. Exportez la version consultable (HTML) via l'onglet « Export consultation »
2. Déposez le fichier sur OneDrive / SharePoint avec un lien de partage
3. Revenez ici et collez l'URL du partage ci-dessous, puis « Générer »
